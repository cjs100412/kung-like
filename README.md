# kung-like (가제) — 모바일 싱글 채굴 성장 게임

타일로 된 지형을 파서 자원을 모으고, 팔아서 돈을 번 뒤, 장비를 강화해 더 빠르게 더 깊이 파는 **모바일 싱글 플레이 채굴/성장 게임**입니다.

## 핵심 루프
1. **굴착**: 타일을 파괴하여 길을 만들고 자원을 채집
2. **수집**: 자원을 인벤토리에 저장(가방 용량 제한)
3. **귀환**: 가방이 차거나 생존 자원이 부족해지면 지상으로 돌아감
4. **판매**: 자원을 팔아 골드 획득
5. **강화**: 드릴/가방/생존 업그레이드 구매
6. **재도전**: 더 깊이 탐사(더 단단한 지층, 더 높은 보상)

## 목표(포트폴리오 관점)
- 게임플레이 시스템(타일 파괴/자원 드롭/업그레이드)을 **명확한 구조로 구현**
- 밸런스 수치를 코드가 아닌 **데이터로 관리(조절 가능)**
- 저장/로드, UI 흐름, 디버그 도구 등 **제품 완성도**를 보여줄 수 있는 형태로 마무리
